# Новогодняя 2048

Веб-версия игры 2048: плитки можно перемещать и объединять, набирать очки, отменять последний ход и сохранять результат в таблицу рекордов.

Сайт: <https://li1vv1.github.io/2048/>

## Стек

HTML, CSS, JavaScript.

## Структура страницы

В `index.html` находится только базовый каркас и подключение стилей и скриптов. Вся страница создаётся динамически из JavaScript с помощью DOM API, с использованием семантических тегов.

## Игровое поле

Поле состоит из 16 клеток, расположенных сеткой 4×4. В начале игры появляются две случайные плитки со значением 2 или 4. Каждое значение плитки имеет свой цвет.

## Движение и очки

При движении плитки сдвигаются в выбранную сторону, а одинаковые числа объединяются. После хода, изменившего поле, в случайной свободной клетке появляется новая плитка со значением 2 или 4.

Повторные слияния за один ход разрешены: ряд [4, 4, 4, 4] при движении влево объединяется в [16, 0, 0, 0] с начислением 32 очков.

Движение и слияние плиток сопровождаются анимацией. Текущий счёт отображается над полем.

## Управление

- на компьютере: стрелки на клавиатуре;
- на телефоне и планшете: свайпы по игровому полю;
- кнопка «Новая игра»: сброс поля и счёта без перезагрузки страницы;
- кнопка «Отменить ход»: возврат поля и счёта к состоянию перед последним ходом;
- кнопка «Рекорды»: открытие таблицы сохранённых результатов.

## Завершение игры

Игра заканчивается, когда доступных ходов больше нет. После завершения появляется сообщение и форма для ввода имени и сохранения результата.

После сохранения форма скрывается, а сообщение меняется на «Ваш рекорд сохранён!». Отменить ход после проигрыша нельзя.

## Таблица рекордов

В отдельном окне отображаются десять лучших сохранённых результатов. Каждая запись содержит имя пользователя, количество очков и дату сохранения. Результаты отсортированы по убыванию очков.

## Сохранение данных

Поле, счёт, предыдущий ход и рекорды сохраняются в localStorage браузера. При загрузке страницы игровая сессия восстанавливается.

## Адаптивность

Макет построен на Grid и Flexbox. Для небольших экранов используются медиазапросы. Оформление дополнено новогодним фоном и анимированной гирляндой.
